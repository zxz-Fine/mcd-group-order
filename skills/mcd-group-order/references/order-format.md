# 报单文本格式与解析规则

`parse_orders.py` 负责把群聊里的报单文本转成结构化 JSON。本文档说明它认哪些写法、不认哪些写法。

## 支持的写法

| 写法 | 示例 | 解析结果 |
|---|---|---|
| `@昵称` 前缀 | `@张三 麦辣鸡腿堡套餐 x1` | 人=张三，餐品=麦辣鸡腿堡套餐 ×1 |
| `昵称：` 前缀 | `李四：巨无霸 + 中薯 + 可乐` | 人=李四，3 个餐品 |
| `昵称 ` 空格前缀 | `王五 2个麦香鱼 1份薯条` | 人=王五，2 个餐品 |
| 中文数量 | `两个麦香鱼` | 麦香鱼 ×2 |
| 后缀数量 | `巨无霸x2` / `巨无霸×2` / `巨无霸*2` | 巨无霸 ×2 |
| 前缀数量 | `2份薯条` / `2杯可乐` | 薯条 ×2 / 可乐 ×2 |
| 备注 | `板烧鸡腿堡 去冰可乐` | 板烧鸡腿堡 + 可乐（备注：去冰） |
| 括号时间戳 | `【12:30】@张三 双层吉士汉堡×2` | 自动剔除时间戳 |
| 独立数量标记 | `麦辣鸡腿堡套餐 x1` | `x1` 回填给前一项，不会当成餐品 |
| 保护 `1+1` | `我 1+1随心配` | 餐品=1+1随心配（数字间的 `+` 不切分） |
| 泛称 | `@周七 随便` | 人=周七，`intent="any"`（待指派为汉堡） |

## 泛称报单（「随便」）

群里总有人只回一句「随便」。这类报单**没有具体餐品**，会被打上 `intent: "any"` 标记，
交由 `assign_any.py` 指派。

**识别的词**（去掉「来个」前缀与「吧/了/呀/来/点/个」等语气后缀后整段匹配）：

```
随便 都行 都可以 随意 无所谓 你定 你们定 你看着办 看着办 看着点 不挑
啥都行 什么都行 吃啥都行 喝啥都行 任意 听你的 听你们的 随你 都随你 随你们
我不挑 都OK 你选 你们选 你帮我选 帮我选 来啥吃啥 给啥吃啥 安排 你安排 随便安排
```

**不算泛称的情况**——已经指定了餐品：

| 输入 | 结果 |
|---|---|
| `随便来个巨无霸` | 餐品=巨无霸（**不是**泛称） |
| `随便来份薯条` | 餐品=薯条（**不是**泛称） |
| `随便` | 泛称，待指派 |

**同一行连续泛称会合并**：`都行，你看着办` 是**一次**「随便」，不是两次——
否则会被指派成两个汉堡。合并时数量取较大者（`随便x2，都行` → 2）。

**备注会保留**：`随便，不要辣` → `intent=any` + `note="不要辣"`，
指派时会用它排除辣味汉堡。

输出里 `any_count` 表示泛称条目数，同时会往 `warnings` 里加一条提示。

## 分隔符

餐品之间可用：空格、`、`、`,`、`，`、`/`、`+`（数字之间的 `+` 除外）。

## 数量识别

- 后缀：`x2` `X2` `×2` `*2` `2个` `2份` `2杯` `2盒` `2套` `2块` `2只` `2支` `2袋` `2瓶`
- 前缀：同上单位
- 中文数字：`一` `两` `二` `三` … `十`

## 备注识别（受控词表）

备注关键词：`不要X`、`去X`/`去掉X`、`少X`、`加X`/`多X`、`换X`、`备注X`。

其中 `X` 取自受控词表：

```
番茄酱 酸黄瓜 沙拉酱 生菜 洋葱 香菜 吸管 餐具 芝士
冰 糖 酱 菜 葱 盐 辣 奶 油 皮 盖
```

**为什么用受控词表？** 两个真实踩过的坑：

1. 若把裸「无」当备注关键词，`巨无霸` 会被拆成 `巨` + 备注 `无霸`。
2. 若用泛化的 `去[^\s]{1,3}`，`去冰可乐` 会被整串吞成备注，丢掉了「可乐」这个餐品。

## 已知边界（交给 LLM 兜底）

脚本是**确定性兜底**，不是主解析器。以下情况请由 LLM 判断，或直接问用户：

- 一句话里混了多人的报单（如 `张三李四都要巨无霸`）
- 「和昨天一样」「老规矩」「加一个那个」这类指代
- 品牌别名与门店黑话（脚本内置了一小张别名表，可在 `match_menu.py` 的 `ALIASES` 里扩展）
- 一个片段里同时含餐品与规格（如 `大杯可乐去冰少糖`）

## 输出结构

```json
{
  "people": ["张三", "周七"],
  "count": 2,
  "item_count": 2,
  "any_count": 1,
  "orders": [
    {
      "person": "张三",
      "items": [{ "name": "麦辣鸡腿堡套餐", "qty": 1, "note": "" }],
      "raw_lines": ["@张三 麦辣鸡腿堡套餐 x1"]
    },
    {
      "person": "周七",
      "items": [{ "name": "随便", "qty": 1, "note": "", "intent": "any" }],
      "raw_lines": ["@周七 随便"]
    }
  ],
  "warnings": ["检测到 1 项「随便」类报单（周七），未指定具体餐品。…"]
}
```

- `person` 为 `__ME__` 表示文本里写的是「我」，需替换为实际姓名。
- `intent` 字段**只在泛称条目上出现**，普通餐品没有这个字段。
- `any_count` 是泛称条目数（0 表示没有）。
